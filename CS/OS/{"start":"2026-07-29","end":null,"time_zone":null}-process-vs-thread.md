# 프로세스와 스레드 차이

운영체제에서 프로세스와 스레드는 중요한 개념이다.

## 프로세스
프로세스는 실행 중인 프로그램을 의미하며, 운영체제에서 독립적인 실행 환경을 가진다. 각 프로세스는 자신의 메모리 공간을 가지며, 다른 프로세스와 메모리를 공유하지 않는다.

## 스레드
스레드는 프로세스 내에서 실행되는 작업의 단위를 말한다. 여러 스레드는 같은 프로세스 내에서 실행되며, 메모리와 자원을 공유할 수 있다. 이는 멀티스레딩을 통해 프로세스의 효율성을 높일 수 있게 해준다.

## 차이점
- **메모리**: 프로세스는 독립적인 메모리 공간을 가지나, 스레드는 같은 프로세스의 메모리를 공유한다.
- **자원 관리**: 프로세스는 OS에 의해 관리되는 반면, 스레드는 프로세스 내에서 관리된다.
- **실행 속도**: 스레드는 가벼워서 프로세스보다 더 빠르게 전환될 수 있다.

## 핵심 정리
프로세스는 독립적이고 메모리를 못 공유하는 반면, 스레드는 메모리를 공유하며 같은 프로세스 내에서 자원을 효율적으로 관리할 수 있다.
